# WorldSkills Kazakhstan 2026 - Web Technologies (Competence 17)
Practice pack: one task + guide per module, with the official time limits.

| Day | Module | Time | Focus |
|-----|--------|------|-------|
| 1 AM | A - Static Website Design | 3h | HTML/CSS, responsive, a11y |
| 1 PM | B - REST API | 3h | Node/Express or PHP, MySQL |
| 2 AM | C - Dynamic site with SSR | 3h | Server framework, auth, OWASP |
| 2 PM | D - Interactive frontend (SPA) | 3h | Uses API from B |
| 3 AM | E - Speed tasks | 3h | Many mini-tasks |
| 3 PM | F - Collaborative AI project | 2h | Team, AI, presentation |

Rules for practice: use a timer, do not look at solutions, validate and test before time ends.
Module D depends on the API you build in Module B (or use the provided JSON in D_spa_frontend/data).
