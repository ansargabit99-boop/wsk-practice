# Guide - Module F

## Time plan
- 0:00-0:15 Pick ONE idea and ONE core feature. Roles: Frontend / Backend or AI logic / Design + presenter
- 0:15-1:30 Build the smallest end-to-end version. Commit often. Use AI for boilerplate, debugging, copy; always review its output.
- 1:30-1:45 Feature freeze. Fix bugs, polish UI, prepare a demo path that you KNOW works.
- 1:45-2:00 Slides (problem/idea, how AI helped, demo), rehearse once with a timer.

## Tips
- Scope small. One flow that works beats five that half work.
- Hardcode fallback data in case an API fails during the demo.
- Prompt AI with specifics: stack, file structure, exact behavior, example input/output.
- Prepare tabs/files before presenting.
- Teamwork is scored: listen, divide work, speak in the presentation.

## Presentation outline
1. Hook (1 sentence problem)
2. Idea origin
3. How we built it (AI tools and what they did)
4. Demo (3 steps max)
5. What next
