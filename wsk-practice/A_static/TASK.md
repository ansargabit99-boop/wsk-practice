# Module A - Static Website Design (3h)

## Task
Client: small travel agency "Steppe Routes".
Build a static 4-page website in pure HTML/CSS: Home, Destinations, About, Contact.

Content: use your own placeholder text and images (e.g. from picsum.photos, downloaded locally) plus one short video.

Requirements
- Responsive at 3 viewports: mobile 375px, tablet 768px, desktop 1440px
- Shared header/nav and footer on all pages; mobile nav (CSS-only burger or stacked links)
- Home: hero image with heading + CTA, 3 feature cards, testimonials
- Destinations: grid of 6 cards (image, title, price, button); 3 cols desktop, 2 tablet, 1 mobile
- About: two-column text + image, timeline or team grid
- Contact: form (name, email, topic select, message, consent checkbox) with proper labels; embedded video or map placeholder
- Accessibility: alt text, heading order, labels, focus styles, contrast >= 4.5:1, skip link, lang attribute
- Valid HTML and CSS (W3C validators, zero errors)
- Works in latest Chrome and Firefox

## Deliverable
Folder with index.html, destinations.html, about.html, contact.html, css/, img/.
