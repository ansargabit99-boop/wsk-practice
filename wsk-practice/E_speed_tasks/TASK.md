# Module E - Speed Tasks (3h)
Ten mini-tasks. Target: finish at least 7. Easy ~10 min, Medium ~20 min, Hard ~35 min.

## Easy
1. **Pricing card**: HTML/CSS card with title, price, feature list with check icons, CTA button, hover effect. Valid HTML/CSS.
2. **debounce(fn, ms)**: calling repeatedly only runs fn once after ms of silence. Return a function with a `.cancel()` method.
3. **Form validation**: email + password (min 8, 1 digit) with inline error messages on blur and submit.
4. **Dark mode toggle**: button toggles theme via CSS variables and remembers the choice.

## Medium
5. **Accordion**: accessible (button, aria-expanded, aria-controls), arrow-key navigation, one open at a time.
6. **Sortable table**: click header to sort asc/desc for strings and numbers; show sort indicator.
7. **Autocomplete**: input filters a list of 50 countries as you type, arrow keys + Enter select, Escape closes.
8. **Toast notifications**: `toast(message, type, ms)` stacked, auto-dismiss, closable, aria-live.

## Hard
9. **Drag-and-drop list**: reorder items with the mouse and with keyboard (Alt+Up/Down).
10. **Custom date picker**: month grid, prev/next month, select a date, min/max dates, keyboard navigation.
